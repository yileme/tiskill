键盘操作

快捷键

沿用桌面 CAT 工具的确认与换段习惯，按本机键位可用 ⌘ 或 ⌃。

⌘/⌃ + ⏎确认当前译文，并跳到下一段
⌘/⌃ + ⇧ + ⏎确认当前译文，但停在原段落
Alt + ↑ / ↓在译文单元格内切换上／下一段
↑ / ↓在网格上移动当前段落
PgUp / PgDn向上／向下翻一屏
⌘/⌃ + A选中当前段落的全部译文
Tab / ⇧ + Tab在译文单元格内跳到下一段／上一段
⌘/⌃ + ⇧ + C把原文填入当前段译文
⌘/⌃ + ⇧ + ⌫清空当前段译文
Esc放弃本段未保存的编辑
⏎在网格上进入当前段落的译文

在段号或原文上右键可以打开段落操作菜单：复制原文到译文、清空译文、确认本段、撤销修改、同步到相同原文、在检索中查找。译文在停止输入约 0.7 秒后自动保存；关闭页面不会丢失已保存内容。
