# Obsidian knowledge library

Accepted 2026-10-18 after explicit user correction. Evidence, expressions and practice belong in a dedicated folder inside the existing Obsidian vault, never a nested vault or CAT feature. Plain Markdown with YAML and wikilinks is the durable format. Local library.json selects the folder; public source contains no private vault path.

CLI saves require explicit confirmation, validate fields/URLs, allocate exclusive filenames and reject duplicate IDs. Verified states require user confirmation and identify the checker; no automated truth claim. Offline migration backs up the legacy SQLite database before exporting every card and attempt with full original JSON, IDs and immutable snapshots. The legacy schema has no general edit-history table; preserve only existing history. Keep the original database. CAT editor, terms, TM and chat remain independent.
