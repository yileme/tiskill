# 0.11.0 分享文案（草稿）

tiskill 更新到 0.11.0，现在共有 10 项技能。新增包容性语言审校：英文或中译英里的代词、性别和身份称谓拿不准时，可以结合原文、本人称谓和客户规范，讨论具体改法。

这次也带上了 0.10.0 的双语译例检索：先找候选，再回查出处和英文用法。搜索可能遇到验证、登录或无关结果，证据不足会保留待核实，不把搜索摘要当结论。

已安装的朋友可重跑安装命令补齐更新；改过技能文件的，先备份。项目和用法：https://github.com/yileme/tiskill

更新命令：

```bash
npx -y skills add yileme/tiskill -g --all
```
