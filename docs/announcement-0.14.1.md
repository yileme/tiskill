# 0.14.1 分享文案

tiskill 0.14.1 已更新，现有 13 项技能。新增医学论文编辑与翻译：支持计划讨论、用户草稿审校和忠实中英互译，保留研究事实，以目标期刊要求为先。术语查证补充术语在线，核对概念、学科、定义、英文与来源，分清已读条目和公布信息待核。公共服务英文译写、外刊伴读等既有功能继续保留。

医学编辑参考 AMA 第 11 版（2020）的选读内容；公开包不含版权 PDF 或全文，不编造研究，也不作医学正确或可发表保证。
