# CAT 验收记录

结论：本地纯文本编辑、保存和三种 DOCX 导出可试用；AI 对话未通过真实端到端验收，不标记全功能通过。

## 已验证

- 8 项自动测试通过：导入、冲突拒绝、修改建议应用与撤销、落盘、导出格式、字体设置、下载文件名、无效参数。
- 浏览器导入三段样稿、输入后立即确认、确认后换段保持状态。
- 自动保存前立即点击导出：导出等待保存成功，服务端含最新输入。
- 页面刷新恢复译文；已确认过滤；Tab 从第一段切换第二段。
- 三种 DOCX 经结构校验及 python-docx 读取；LibreOffice 转为 PDF，人工查看页面，无中文缺字或表格截断。
- 默认 8765 服务已重启加载新代码，默认项目保留 6 段；默认端口 DOCX 导出返回有效 ZIP 文件头。

## 本次修复

保存队列在实际发送时读取版本号；显式确认与普通失焦保存区分；导出先保存，失败中断下载；清理自动保存计时器；阻止键盘事件重复触发；Markdown 表格转义；HTML 字体优先级；空项目状态控制。

## 尚未通过／限制

- 真实 Ollama 对话请求超时，页面显示“本地模型未响应”。因此真实模型生成建议→应用→撤销链路尚未通过，不能宣传 AI 助手稳定可用。提议应用与撤销接口测试通过不替代真实模型验收。
- DOCX 指定 SimSun / Arial，不嵌入字体。本机没有 SimSun；LibreOffice 字体搜索路径需显式指定，中文预览回退到 Songti SC。未在 Microsoft Word 中验证精确宋体字形。
- 样例为三段短稿，长文表格跨页、复杂格式和完整多用户并发未验收。
- 未发布新版本；当前为本地试用代码。

## 后续验收：Agent 与资源面板

已改用本机 Codex Agent，移除 Ollama 调用。真实测试完成：问答返回、完整译文提议、点击应用后服务器译文更新。页面显示 CODEX AGENT，失败记录保留于讨论栏。Ekko Studio 原生 chat-run 桥返回 Authentication failed；未声称直接接入当前 Ekko 会话。

20 项自动测试通过。术语库按语言方向添加/检索/插入；记忆库只显式收录已确认且版本一致的译段；浏览器检索到完全匹配。所有验收写入独立 8766 样稿数据，默认 8765 的现有译稿保留。TM 相似度为本地规范化字符算法，非 memoQ/Trados 标准，尚无 TMX/TBX 互通。


## Agent 与资源面板追加验收

默认讨论后端已切换为本机 Codex Agent。浏览器向第 2 段发送“做人的道理”两个译法比较问题，真实返回中文说明及整段修改建议；译文未自动覆盖。此为独立 Agent 请求，携带本段历史，不共享当前 Ekko 开发会话。Ekko 直接桥接未接通，不宣称等同于当前会话。

资源、服务端和导出共 19 项测试通过。术语与记忆库标签已在默认页面显示；记忆库只允许显式保存已确认且版本一致的段落，按语言方向隔离。字符相似度仅为本地检索提示，不等同 memoQ/Trados 匹配分数。真实界面截图已检查，无面板内容截断。

## 三层侧栏与 CSV 验收

术语库→记忆库（含项目检索）→讨论，移除段落页。浏览器实测原文“设备”与译文 device 选区配对进入添加窗口；修改译法为 equipment 后接口返回已更新内容。资源库 CSV 导入、挂载/卸载、并发编辑冲突、旧 JSON 保留迁移及换行引号等测试通过，共 30 项测试。

在线术语 Agent 实测查询 clinical trial，返回 NIH 与 NCI 的链接和引文，并明确热词译超时；站点可访问性不保证。快捷检查真实加载仓库 skill 文本，不只是提示词按钮标签。低高度窗口采用右栏滚动，避免输入框和结果被压没。
