# 0.11.0 变更说明

新增第十项技能 `tis-inclusive-language`，处理英文和中译英中的包容性语言、性别、代词与身份措辞。四档反馈区分必要修正、有条件建议、保留与待核实，分开原文、翻译转移和客户规范。默认只处理用户问题或当前相关局部问题，不增加每篇翻译的强制扫描。

来源为 UN 英文性别包容性指南与 APA 2023 第二版；保留 singular they 的实际分歧及美国/机构适用范围。尊重本人自称，不抹掉女性经验，不改引文、历史、法律或医疗统计范围。仅分发原创释义与来源定位；[阅读和视觉核对范围](../skills/tis-inclusive-language/references/sources.md)明确区分已核对页面与未核对内容。

入口和三项相关技能增加简短局部交接；插件、同步允许列表、版本和 README 同步更新，共享反馈文件保持一致。CAT 和私有知识目录不变。设计见 [ADR](adr/0005-inclusive-language.md)，[八项人工验收](inclusive-language-acceptance.md)是编写的测试输入与标准，不是真实模型通过记录。

本次公开发布包含 0.10.0 的双语译例检索更新，从公开 0.9.2 快照追加提交至 0.11.0；不合并本地开发历史。
