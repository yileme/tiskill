# 0.13.0：公共服务英文译写

新增 `/tis-public-service-english`，tiskill 现有 12 项技能。可处理公共场所名称、标志、导向、警示、指令与短通知的单条中译英、双语审校和批量待审记录，覆盖 GB/T 30240 通则及九个领域。

使用时提供原文、实际位置与功能、受众、目标地区、正式名称和客户术语要求；结果区分建议译文、适用条件、来源定位、证据状态与待确认项。批量 CLI 只校验输入并生成待审记录，不自动翻译，也不提供语义评分。

例如，健身房要求运动时穿上衣，可提出 **Shirts must be worn while exercising.** 这是按该场景编写的建议（proposed），不是标准引文；仍须确认场馆政策与提示位置。

## 安装与来源边界

技能自带参考与 Python 3.10+ 标准库 CLI，可独立安装。其他 tiskill 技能是可选协作项。规则摘要为独立撰写，保留标准版本、条款与页码，公开包不含标准全文、原始 PDF、MinerU 提取文件、OCR 文本或完整术语索引。

本地标准检索需另行配置私有来源登记与索引。未配置时，可依据用户提供的材料继续工作，并明确本次未查询本地标准；安装公开包不会获得完整标准库或术语库。

来源元数据记录：2026-10-23 查询官方十份标准详情页时均显示“现行”。这是查询时的状态快照，项目使用时应重新核对。GB/T 为推荐性标准，法律、合同及客户采用条件另查；所列十份标准的附录均为资料性，例译不是所有场景下的唯一强制译法。

## 核验范围

既有本地来源验收记录显示：74 个图像布局块已恢复为 OCR 候选；十条代表记录（每部分一条）做过原件视觉比对，仅标记转录核对。私有索引另有 9,116 条候选出现记录，含重复和重叠，不是独立术语数，也不是已核验词条数。源资料与索引不随公开包分发。

自动测试覆盖路径隔离、缺少来源登记、候选排除、领域筛选、来源追踪、不可覆盖输出和批量结构等边界。30 个领域场景仍是人工验收标准，不是已执行的模型能力评测；未做全文逐行校对或现场标牌验收。详见[验收记录](public-service-acceptance.md)与[来源边界](../skills/tis-public-service-english/references/evidence.md)。
