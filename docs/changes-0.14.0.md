# 0.14.0

新增第 13 项技能 tis-medical-paper；请求简称 ti-medical-paper 由入口识别，未增加独立别名安装目录。支持医学论文计划、用户草稿审校、忠实中英互译和报告完整性查询；不从提纲编造整篇研究论文。目标期刊要求优先，保留统计量、终点、人群、药物和单位。

AMA 11 (2020) 仅为有明确定位的编辑来源；版权 PDF、批次全文与图片保留本地。独立只读 lookup.py 使用可选私有配置，返回待核实的提取候选；无来源配置仍支持用户材料审校。未核对 2020 年后 AMA 修订或报告清单最新版。见 [验收](medical-paper-acceptance.md)。本次为本地实现与提交，未发布远端。
