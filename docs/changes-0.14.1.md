# 0.14.1：医学论文技能与术语查证

本次公开更新合并 0.14.0 与 0.14.1，技能总数由 12 增至 **13**。公共服务英文译写、阅读伴读及既有技能继续保留。

## 新增医学论文编辑与翻译（0.14.0）

新增 [`tis-medical-paper`](../skills/tis-medical-paper/SKILL.md)，支持计划与结构讨论、用户已有草稿审校、忠实中英互译，以及按实际材料查询报告完整性。`ti-medical-paper` 是入口可识别的请求简称，安装名仍为 `tis-medical-paper`。

目标期刊的实际作者要求优先；审校保留研究人群、设计、终点、统计量、不确定性、药名与单位。实质研究文本由用户起草；只有提纲或数据时提供结构建议和作者查询，不制造研究、结果、伦理批准、引文或整篇研究论文。

编辑参考 AMA Manual of Style **第 11 版（2020）**。已读书目、目录、前言及选定章节段落，实际页码范围见[来源定位](../skills/tis-medical-paper/references/sources.md)。1250 个物理页完成七批本地转换，不代表全书逐页精读、表格完整转录或当前规则全部核实；2020 年后修订及报告清单最新版仍需按任务另查。转换、查读与人工核实分别记录。

公开分发仅含原创指导、书目定位和独立只读检索脚本。AMA 源 PDF、分批 PDF、全文 Markdown/JSON、OCR、图片、私有路径与源文件哈希不进入公开包。可选私有来源查询返回提取候选，仍须回查 PDF；无私有配置也可审校用户材料。详见[医学验收与限制](medical-paper-acceptance.md)。

## 完善术语在线查证（0.14.1）

[`tis-usage-evidence`](../skills/tis-usage-evidence/SKILL.md) 增加[术语在线协议](../skills/tis-usage-evidence/references/termonline.md)：通过真实界面阅读概念、学科、定义、规范名称、英文、具体来源和可见公布年度；缺失的版次等字段不补造。不同学科同名条目分别比较，目标语搭配与本句适用性另查，客户简报冲突明确列出。

实查读过官网身份页和一条妇科肿瘤学“随机对照试验”基本释义：来源“妇科肿瘤学名词”，页面公布年度“2022”。这是条目元数据；独立公布文件仍待核，不能把“已读条目”写成“公布程序已核实”。其他同名记录未逐一打开。见[实查记录](termonline-acceptance.md)。

搜索包含动态参数，未验证稳定 URL 或公开 API 契约；本版通过实际浏览器界面操作，没有新增术语在线 URL 生成器或网络接口。生成链接、读取条目、来源公布核验与本句判断分别记录。

## 安装与验证范围

安装或更新全部 13 项技能：

```bash
npx -y skills add yileme/tiskill -g --all
```

重装前请备份自行修改的文件。自动检查覆盖版本与插件元数据、来源定位及链接、医学只读检索、更新与修改保护，以及相关公共服务、双语和阅读回归；不代表医学语义、翻译质量、学习效果或可发表性的认证。AMA、相关机构和来源作者不为本项目作官方背书。

本次从既有公开 main 追加审计快照，保留独立公开历史；版本说明以本文和[分享文案](announcement-0.14.1.md)提供，不创建 tag 或 GitHub Release。
