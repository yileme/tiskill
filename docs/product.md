# tiskill 是什么？它有哪些能力？

tiskill 帮你对照原文和初稿，找出该改的一处，说明依据，再练一次。它将笔译练习、译文诊断、英文用法查证和简明语言改写与审校拆成可单独调用的步骤。当前版本为 0.11.0，共 10 项技能。

## 怎么开始？

在已安装的 Agent 中调用 `/tis`，提交原文、译文以及读者、用途和目标语言地区要求。已有明确任务时，也可以直接调用下列子技能。安装说明与仓库位置见 [README](../README.md)。

## 目前有哪些能力？

- `/tis-translation-practice`：在动笔前整理任务要求、比较关键译法，在译后生成针对文本的自查项。
- `/tis-translation-diagnosis`：对照原文和初稿，给出教练式讲评、修改依据与针对性练习。ATA 错误类别只用于教学，不构成官方评分。
- `/tis-real-english`：筛查中译英中的表达风险，区分可核实问题与风格选择。
- `/tis-usage-evidence`：查证英文词义、搭配和语域，给出可回溯的词典或语料依据。
- `/tis-plain-language`：按目的、读者与目标语言改清楚公众、教育、健康、行政、商务、技术和本地化文本；选择最小修改、重写或诊断，删无贡献重复，保留事实、术语和译文忠实。适用于英文与简体中文，不检测 AI 作者身份。
- `/tis-inclusive-language`：按请求审校英文或中译英的代词、性别与身份表达，区分必要修正、有条件建议、保留与待核实。
- `/tis-update`：在明确要求更新时检查并同步本机安装的技能副本，保留用户修改。

本地 CAT 页面支持逐段编辑、保存、聊天提议和确认修改；启动和模型接入方式见 [CAT 使用说明](../cat/README.md)。页面聊天是独立会话。真实材料的听辨、跟读、复述与自评可用；客户业务简报、报价与授权建档已可用；完整口译训练仍在规划中。

## 一次最简单的使用

发送：`/tis-plain-language 请审校这份英译中文技术说明。目标地区 zh-CN，读者是首次使用该功能的人。原文：…… 译文：……`。返回的修改应标明语义问题与风格优化，并说明改动依据。

## 客户业务

`/tis-client-service` 从真实沟通整理笔译、口译、本地化简报与报价，交付JSON、Markdown、沟通草稿和变更记录。缺项保留待确认，报价不表示合同成立。授权后使用本地CLI建立未签约项目；无客户材料只提供模板。知识与项目分别在配置的Obsidian目录05-业务知识和06-客户项目，详见 [业务说明](business.md)。不会发送消息或上传客户数据。
