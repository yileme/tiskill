# 业务知识

## 笔译流程与旧称

GB/T2022 PDF p10/正文 p2 §§3.2.5–3.2.8 与 PDF pp17–18/正文 pp9–10 §6.3：

| 2022术语 | 工作区别 |
| --- | --- |
| 笔译 | 按用途、语言规范、领域术语与格式生成译文（6.3.1） |
| 自检 check | 笔译员全面检查自身译文并修正（6.3.2） |
| 双语审校 revision | 另一名具备相应能力的人员对照源文检查译文（6.3.3） |
| 单语审校 review | 按约定对译文用途、领域与文本惯例作单语检查（6.3.4） |
| 校对 proofread | 印制前检查已经双语审校的译文并完成修正，按约定提供（3.2.8、6.3.5） |
| 最终核验与交付 | 项目经理对照项目规范核验，缺陷修正后交付（6.3.6） |

旧2014“翻译=翻译+校对+审核”不是2022阶段定义。先询问旧校对是对照原文的双语审校、单语领域检查还是印前校对；旧审核也不能自动当作单语审校或最终核验。记录旧称、实际动作、人员和新称映射依据，未确认时 pending。若约定按 GB/T2022 提供服务，不能用译者自检替代另一人的双语审校。单语审校、校对按约定；不要自动塞进报价或把条件步骤删除。该标准不是 MTPE/口译服务符合性依据。

咨询先检查目的/受众/地区、语言方向、文件版本、源文是否最终、数量口径、格式媒介、进度与人员资源（GB §§5.2–5.6、附录 B/C；ATA笔译 p5）。口头约定书面确认，变更先获各方同意并与原约定保存（GB §5.4）。保密、版权/TM使用限制、存储销毁与适用法必须约定；附录 B 的付款举例不设默认。结项检查客户反馈、修正、重交、归档和数据保护（GB §7）。

2014摘录成本项：译前准备（页/小时）、翻译（字词/页/项）、图表编辑（图/小时）、桌面排版（页/小时）、术语与TM创建维护（小时）、项目管理（选定其他项目小计百分比）。明确原文/译文计数、字/词/字符与空格口径、软件统计、千字或每字单价；2022前言明确删除旧计字方法（PDF p5），不能暗示某一口径是2022强制。

## 口译

用户2014业务分类：交替传译{陪同交传、会议交传、远程交传}；同声传译{耳语同传、会议同传、远程同传}。ATA口译 pp4–5 区分 mode 与 modality：远程是交付方式，耳语属于同传，视译另行识别；手语需求也须明确。

采集语言方向/变体、日期与时区、起止与休息、地点或远程平台、参与者人数与角色、译员数量/搭配、主题背景、联系人、资料提交、准备/技术测试与设备责任。AIIC p2 arts1–4、p3 arts8–11 提供能力、保密、独立公正、准时、忠实与错误修正的职业参照；p4 §15.1–15.4、p5 §15.5 提醒视听、轮换、传译链、隔音和提前资料/简报。适用范围保持 AIIC 会员规则，不暗示用户是会员或认证。

报价=译员人数×每人约定计费时间×单价 + 明确的超时、交通、住宿、设备、通信、协调成本。已给“人天”总量不再乘人数或天数。2014建议半天起、超过半天按全天，但摘录没有小时数，必须约定半天/全天定义、最低收费和跨日处理；不是法定费率。ATA p6 的最低收费/取消费用提示仍需具体合同约定。远程平台、测试、备份音频和保密录制许可需确认。

## 系数与本地化

用户T/TAC2020摘录：工作量×基础单价×难度×资格×翻译类型×Σ流程分项 + 条件费用 + 附加费用。流程系数求和，绝不连乘。无自动系数；范围只是用户摘录，不生成资质或收费结论。

| 因子 | 摘录范围 |
| --- | --- |
| 难度 | 低0–1、中1、高1–2 |
| 资格 | 初级1、中级1–3、副高3–5、正高5–10 |
| 类型 | MTPE 0.3–1、人工1 |
| 流程 | 技术0–0.2；术语0–0.1；预处理0–0.1；风格0–0.5；PM 0.1–0.2；初译/自检1；双语0.2–1；单语可选0.1–0.5；校对可选0.05–0.5；终验0.05–0.5；QA0–0.2；术语TM维护0–0.05 |

2013本地化摘录：软件/文档逐任务用小时×时薪、加权词数×单价或图/页计价；加权词数须列实际分组字数与权重及统计依据。范围可涵盖工程准备、翻译、图中文字、图像处理、排版、构建与测试，逐项选择；不是自动包含。图中文字不能既算翻译又重复计同一翻译任务；图像编辑可作为不同工作。PM仅对选定且未含PM的小计计收，不能对税、另一个PM或含PM的系数范围再收。折扣、税和加急需明确规则，未知不是免费。
