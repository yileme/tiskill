# tis-inclusive-language：包容性语言审校

先读 [反馈与对话](references/voice-and-interaction.md) 与 [来源及适用条件](references/sources.md)。第一版处理英文写作与中译英中的性别、代词和身份称谓；其他语言、地区术语或最新机构规定没有证据时保留待核实。

用户明确问包容性语言、性别、代词、身份表达，或当前审校出现相关局部问题时使用。用户只问一处就处理一处；只有明确要求全文包容性审校才扩大范围。来源指南不授权每次翻译自动扫描全文，不自动串联其他技能。

## 判断顺序

1. 沿用已有原文、译文、受众、地区、年代、用途、本人称谓和客户规范。只问会改变结论的缺口；单语编辑不能宣称已核对翻译忠实。没有个人代词资料时不凭姓名、职业、外貌、声音、婚姻状况或国籍猜测身份。
2. 分开三件事：**原文表达**是否本来就在呈现某种身份或立场；**翻译转移**是否增添、遗漏或改变了含义；**机构偏好**是否适用于本客户、文体与版本。原文可讨论的措辞不自动成为译者错误，客户偏好不自动成为普遍语言规则。
3. 先锁定意义，再提出最小编辑。保留引文、历史用语、法律定义、正式名称/职衔、医学分类、统计分组与分母、当事人自称、说话者立场，以及歧视、暴力或伤害的准确描述。不用委婉语淡化伤害，也不把忠实转述改成作者赞同。需解释时在引文外补注；改编须有任务授权并明确标示。
4. 按下方四档反馈。推荐替换前核对指代、事实、群体范围、语体和客户条件；不按词表逐词替换，不推断作者或译者的道德品质、意图或政治立场。指南建议本身不证明现实伤害或读者反应，影响解释须具体且有条件。
5. 默认用一两段：具体片段 → 在本句可能造成的理解 → 原文/本人资料/客户条款或来源章节及范围 → 最小改法及条件。无需四个标题或大报告。无问题直接说可保留；不凑建议，不强加练习或自动保存。

## 四档反馈

- **必要修正 / necessary correction**：有证据的事实误称、违背已知本人代词、译文无依据添加性别/身份，或违反明确适用的客户规范。说明依据类型；客户规则冲突若需改变事实或法律范围，先标待确认，不执行失真改写。
- **有条件建议 / conditional suggestion**：现文可成立，但特定受众、场景或选定指南支持另一种写法。交代什么条件下采用，不能记成错误或普遍禁语。
- **保留 / retain**：本人自称、相关女性经验、精确分组、引文或官方名称等有保留理由；也包括已经清楚准确的表达。不为了显得包容而全篇去性别化。
- **待核实 / pending**：本人代词、原文指向、地区惯例、适用客户规则或最新版本不足。明确缺哪一项；能用姓名、职务或省略代词保留原意时先给该方案，不猜一个身份填上。

## 常见任务

**代词与称呼。** 已知本人代词就准确使用；未知时可重复姓名/角色或改写。APA 2023 接受未知或泛指个体的 singular they；本次 UN 文本 §3.2 把这一策略限于非正式写作，不推荐正式文本使用。不得把两者说成一致。按适用客户规范选择；客户未定时给条件选项，不能宣称 they 不合语法或一律必用。用 they 避免猜测，不据此断言该人非二元身份。称呼对等，保留本人明确使用的职衔与称谓。

**中译英。** “医生”“负责人”“配偶”等不提供性别时，不增加 male/female、he/she 或 husband/wife；可用 doctor、person responsible、spouse 等与原文相符的表达。原文明确“女工”“母亲”“女性患者”且与经验、指涉或研究范围有关时保留；不能仅为中性化改成全体 workers/parents/patients。中文“他”在具体材料中是泛指还是特指须结合上下文，不自动认定；口语 tā 不提供书面性别证据。源文有贬抑、讽刺或历史视角时忠实呈现并按需另注，不代作者改变立场。

**残障与身份。** person-first 与 identity-first 均可能适当；本人明确偏好优先于一般风格建议。不要把 autistic person 或 Deaf person 自动改成 person with ...。未知时参考特定群体/地区证据，不能把群体倾向当成某个人的偏好。普通描述可条件性建议 wheelchair user；不得由一个标签推断诊断、疾病严重程度或生活经历。

**范围与精度。** 性别在女性处境、临床对象、统计或法律中可能必要。怀孕相关语言依实际受众与群体选用，既不漏掉目标群体，也不抹掉女性经验。不要把不同身份、性取向、sex、gender 或医学概念混为同义词；正式法律词和机构名称不得按 APA 表自动改写。

一般用法有争议且需要实时证据时可用 `tis-usage-evidence`；需要更大范围简明改写或教学诊断时按用户目标接续。只交回已解决的局部问题，同一底层错误只记一次；有条件建议和待核实项不进入错误累计。
