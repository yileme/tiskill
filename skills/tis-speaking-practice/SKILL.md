# tis-speaking-practice：真实语境听说练习

先读 [反馈与对话](references/voice-and-interaction.md)，按其规则控制讲评篇幅和语气；下文的证据、任务与保存边界仍须遵守。

范围：一条真实短材料、一个目标表达、一次产出和一次复盘。不是口译认证评分，也不提供自动发音打分。复用已有语境、水平和目的；未知时使用短句和中文说明，不先安排长问卷。

1. **确认材料可用性**。优先用户提供的音视频、真实链接或已保存证据卡。来源路由见 `tis-usage-evidence/references/sources.md`：YouGlish / PlayPhrase 可发现音视频片段，实际打开并定位后才能引用。不得编造视频、字幕、说话人、时间点或 API。访问受限、仅有搜索入口或无法播放：标“待核实”，保留待办；可先做基于可见文字的复述，但不能称已听音频。
2. **标清证据状态**。`unverified`=未取得可核材料；`text_read`=实际读到原文，仅支持文本观察；`audio_checked`=本环境确实听取音频或用户明确表示已听取。注明谁核对、访问范围与限制；用户确认不等于模型听过。字幕与音频不一致时分别记录，不以字幕证明发音。
3. **一次只选一个阶段**。听辨：先听短片段，用自己的话记主旨，再对照真实转写；跟读：按可听到的意群模仿一次，不猜重音；复述：遮住文本，用 2–3 句保留事实；情景输出：换一个贴近用户的场景复用表达，标明这是练习题而非来源引文。只读到文字时可做后两项，明确跳过声音层反馈。
4. **等待真实产出再反馈**。收到可处理的用户录音且实际听取后，才能评论所听到的清晰度、停顿或节奏，并引用可定位片段。环境不能听录音时直接说明，提供用户自评清单；收到转写只评价内容、用词与组织，不评发音、流利度或声调。用户自评单独标注，不伪装成系统测量。
5. **复盘与保存**。有实际依据时指出一个做对的点，再给一个下一次动作；续答引用用户本次产出，比较上次目标是否做到；不凭空给 CEFR 等级。用户要求保存时输出可复制的卡片/练习记录，或在用户要求时保存到已配置的 Obsidian 知识目录。保留来源 URL、实际时间点（没有就空）、短引文、语境、领域、语域、状态、核对者和限制；练习记录含回答、自评和日期。不得暗示聊天内容已自动落盘。

建议提示：听懂主旨了吗？能脱离字幕复述吗？目标表达在新场景是否合适？这三项是用户自评，不是自动评分。任何来源不足的项都可以保持待核实。

## 可选 Obsidian 保存

查证、表达积累和练习复盘属于现有 Obsidian vault 内的 tiskill 文件夹，不放入 CAT。默认在对话中输出；用户明确要求保存才写入。先读取 `~/.tiskill/library.json` 的 `path`（配置不存在时不猜测私人路径），用 `~/.tiskill/source.json` 的 `repo` 找到仓库及 `docs/library.md` 的 JSON 输入契约。可直接按目录内模板写 Markdown，或运行 `python3 <repo>/tools/library.py save --input <record.json> --confirm`；此参数只表达已有保存授权，不代替实际核实。

查证保存到 `01-查证记录`，表达到 `02-表达积累`，回答和自评到 `03-练习复盘`。文件名 `YYYYMMDD_主题_V01.md`，保留 ID、日期、来源、限制与核对者；待核实 `unverified` 与 `text_read` / `audio_checked` 分开。CLI 已核实状态要求用户确实核对并明确确认，不从链接、字幕或生成内容推定。练习可引用已存记录的 `sourceId`，CLI 保存当时完整快照；没有来源时保持待核实，不编造来源。模型练习题标作练习，不作为真实引文。保存后检查文件存在，返回实际文件链接；同名使用新版本，已有 ID 不覆盖。
