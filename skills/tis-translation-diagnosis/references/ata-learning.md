# ATA 学习路径（考试资料）

- [How the Exam is Graded](https://www.atanet.org/certification/how-the-exam-is-graded/)：总览 ATA 认证考试如何评阅。先看考试任务与评分语境。
- [Framework for Standardized Error Marking](https://www.atanet.org/certification/how-the-exam-is-graded/error-marking/)：错误类别、代码与考试的标记框架；本教学报告不移植其点数或合格线。
- [Explanation of Error Categories](https://www.atanet.org/certification/how-the-exam-is-graded/error-categories/)：逐类理解译入语规范、意义传达和文字质量，结合具体错误阅读。
- [Flowchart for Error Point Decisions](https://www.atanet.org/certification/how-the-exam-is-graded/error-points/)：从原文对照、理解程度与用途判断问题的影响；不要把图中考分直接套到练习。
- [Into-English Grading Standards](https://www.atanet.org/certification/how-the-exam-is-graded/into-english-standards/)：译入美式英语的具体评阅规范；其他地区英语或译出英语时不要照搬。
