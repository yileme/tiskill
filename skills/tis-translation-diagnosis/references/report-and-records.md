# 一次练习的教学讲评与追踪字段

本结构用于完整诊断和归档。局部问答及续答保留判断、具体引文、依据和最小改法即可，不强制以下标题；涉及 ATA 时仍需来源及非官方边界。

## 报告顺序

1. `# 笔译诊断｜<练习标题> (<exercise_id>)`：方向、用途/受众/变体、检查范围、必要假设；简要复述原文与译文（篇幅长时链接原件，避免重复全文）。
2. **这次你做对了什么**：只有能从文本直接看到时才说，具体到表达/意义；没有可支持的优点就跳过。
3. **先改这几处**：表头 `编号｜原文 → 初稿｜类别／优先级｜讲解：读者会理解成什么｜修改与理由｜依据`。每项只选一个主类别，并写成“本次教学归类”；边界难判时说明备选类别及为何暂取该类，不把类别缩写或“关键”写成 ATA 考官的正式判分。原文对照直接引用，英语用法事实需附当次查到的词典/语料短引语与可点击实际地址。逐项用两三句话像老师解释判断链，不堆术语。待核实、可接受的替代写法另列，不能充作确定错误。
4. **你来试改**：给完整的一个合理修改示例（仅已核对的部分）；如改法需要未核实的语料则别冒充定稿。
5. **下次练什么**：按本次可观察机制设计 2–3 个新句或自查动作，留待学生作答，给逐项成功标准，不立即泄露答案。
6. **这节课的元语言**：1–2 个本次真正用到的术语，每项用“术语→这次的例子→下次自问”三步说明。比如“意义传达→‘尚未’译成‘已经’→读者会得到相反结论吗？”
7. **错误追踪和保存**：给已确认错误的类别计数和简短 CSV 预览；提示可保存本地或指定飞书/腾讯目的地，不虚报已写入。
8. **从考官视角继续学**：链接 ATA 总览、类别说明，按本次主题另选标记框架、流程图或 Into-English；明确是 ATA 学习资料，报告是独立教学反馈。

## 错误表（UTF-8 CSV，每项一行）

字段顺序：`exercise_id,exercise_date,direction,brief,coverage,issue_id,category,priority,source_span,target_span,reason,evidence_type,evidence_url,revision,review_status`。`category` 为单个主要 ATA 缩写；`priority` 为“关键/较大/较小”；`review_status` 写“已确认”。未查实者只留在 Markdown 的“待核实”节，不进入频次表。每次相同 `exercise_id + issue_id` 不重复追加；改判需要显式说明再更新那行。原文/译文片段只截必要短句，避免把保密稿整篇灌入云端表格。

示例表头见 `../templates/errors.csv`。统计按 `category` 对 status=已确认的行计数，并显示纳入的练习数和覆盖范围；同一底层问题只计一次，第二次练习再犯是新的一行。Markdown 适合讲清“为什么”，CSV/在线表格适合汇总“哪类常见”；只要一份时先给 Markdown，其中嵌一张简短记录表。

若用户只请求导出到飞书/腾讯文档，先生成同样的 Markdown 内容与错误行，写入用户指定位置并检查可读性；任何跨平台导入失败都如实告知可下载/可复制的文件位置。
