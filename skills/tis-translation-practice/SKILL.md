# tis-translation-practice｜先判断，再动笔

先读 [反馈与对话](references/voice-and-interaction.md)，按其规则控制讲评篇幅和语气；下文的证据、任务与保存边界仍须遵守。

本技能从用户现有 `monterey-translation-framework` v2.0.0 中提炼任务分析、语境理解、候选译法比较和译后自查的工作方式，是针对具体任务的应用，不是蒙特雷国际研究学院官方标准，也不代表列出的教授逐项认可本技能。不要复制来源材料的长篇例句或版权章节。源技能与其用户约定的单向同步链独立维护；修改本技能不等于修改源技能。

## 输入与路线

尽量取得原文、译向、读者、媒介、用途、地区变体、客户术语或禁用工具要求；缺少非关键说明时写出暂定假设并继续。只有任务尚无原文且缺少它会影响实际译法时才追问。用户只问局部表达时只分析那处，不强行扩展整稿。

1. **任务分析卡**：用简短条目写明谁要读、为了什么读、文本中哪些信息不能变（否定、数字、指称、立场、文化隐喻）、哪些条件尚未知。可按信息密集和文体敏感程度确定检查重点；“硬/软文本”是粗略观察，不是决定译法的唯一开关。真实委托若涉及保密或工具限制，先尊重任务约束，不因文本类型就默认机译可用。
2. **挑选 1–3 个关键难点**：先说明原文该处在上下文的意思和功能。各给两个真正可行的候选译法及读者得到的信息、语气和使用条件；如果某个候选明显失真，明确标明为什么不采用，不凑两个平庸答案。长短句、主动被动、增译、文化解释和词性转换都是可测试的选项，不能作为“汉译英必合句”等固定规则。禁止擅加因果、动机、评价或原文没有的人物。
3. **证据与取舍**：若取舍依赖英语词义、搭配、语域或专业用法，调用 `tis-usage-evidence` 做当次查证并给出处；无可核证依据时注明待核实，不给唯一译法。用户已有初稿时，可以调用 `tis-real-english` 找表达风险，再让 `tis-usage-evidence` 核实；不能因为书中列过某结构就判错。
4. **交付**：局部问题只给当前取舍、理由和可试的改法，不强制整张卡；完整任务分析时输出“任务分析卡 → 难点/候选/取舍 → 可试写版本或局部示范 → 译后自查清单”，默认让学习者先自己译；用户要求完整译文时才给完整参考稿，并强调允许其他可证成的选择。自查先按原文检查意义和完整性，再独立读译文检查目标语和风格，最后核对数字、名称、术语、格式及任务说明。
5. **诊断接力**：收到学生译稿并要求教学诊断，交 `tis-translation-diagnosis`；向诊断传递任务说明、原文含义、可接受选项和已查证据，不把实践卡上的偏好当成 ATA 错误。后续按错误机制安排再练习。

## 输出形式

- **任务分析卡**：译向｜用途与读者｜必须保留的信息｜暂定条件。
- **关键决策**：原文片段｜A/B 候选｜各自代价和适用条件｜推荐及理由/待查证项。
- **译后自查**：原文意义、译入语可读性、任务约束三组针对这篇文本的问题。

对学生讲清“为什么选择”，语气如同翻译课共同推敲稿件；没有原文对照或实际查证的地方不写成确定错误。

## 可选 Obsidian 保存

查证、表达积累和练习复盘属于现有 Obsidian vault 内的 tiskill 文件夹，不放入 CAT。默认在对话中输出；用户明确要求保存才写入。先读取 `~/.tiskill/library.json` 的 `path`（配置不存在时不猜测私人路径），用 `~/.tiskill/source.json` 的 `repo` 找到仓库及 `docs/library.md` 的 JSON 输入契约。可直接按目录内模板写 Markdown，或运行 `python3 <repo>/tools/library.py save --input <record.json> --confirm`；此参数只表达已有保存授权，不代替实际核实。

查证保存到 `01-查证记录`，表达到 `02-表达积累`，回答和自评到 `03-练习复盘`。文件名 `YYYYMMDD_主题_V01.md`，保留 ID、日期、来源、限制与核对者；待核实 `unverified` 与 `text_read` / `audio_checked` 分开。CLI 已核实状态要求用户确实核对并明确确认，不从链接、字幕或生成内容推定。练习可引用已存记录的 `sourceId`，CLI 保存当时完整快照；没有来源时保持待核实，不编造来源。模型练习题标作练习，不作为真实引文。保存后检查文件存在，返回实际文件链接；同名使用新版本，已有 ID 不覆盖。

处理欧盟材料、术语概念或机构用法判断时，读 [EU 指南的任务边界与逐页依据](references/eu-guides.md)。先区分概念、实际用法和客户出版规范；不得据机构词表自动判错或更改原意。

英文译文有长插入语、隐藏条件或压缩从句问题时，读 [Clear English 句法检查](references/clear-english.md)，先核对句界权限与意义，再采用局部简化。
