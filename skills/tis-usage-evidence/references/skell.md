# SkELL：从查询入口到可引用用例

SkELL 已是本技能的来源；这里细化操作，不新增词典或网络 API。沿用当前句子、原文、受众与用途，先明确要验证的词块、义项或语法关系。词典受阻时可用 SkELL 已读例句支持有限的用法观察；不能把语料例句冒充词典释义，词义/语域证据缺口仍需保留。

## 查询与读取

1. **多词短语先用 Examples / concordance**：例如 `status quo`，保留空格，不改成 `statusquo`。选择 English，核对查询框、当前标签和实际结果。Examples 可查词或短语；按[官方帮助](https://www.sketchengine.eu/skell/)不区分大小写，基本形式也可能返回屈折形式及不同词性，逐句核查，勿假定严格字面匹配。
2. **搭配发现用 Word Sketch**：先查单个 lemma（基本形式），核对默认/所选词性，再读主语、宾语、修饰语等关系。官方指示 “Type a word in its base form and click Word Sketch.”；默认先显示最常见词性。点击相关搭配读 Examples，确认关系与义项，必要时用 Context 看较宽的典型组合。此推荐路径不等于已证明所有多词短语不受支持；具体输入是否有可用 Word Sketch 以当次界面为准。Similar words 不能直接证明同义或可替换。
3. **用正常浏览器加载**下方链接，待结果出现再读取；初次仅空壳可再观察加载状态。`#result?...` 是浏览器处理的 URL fragment，不发送给 HTTP 服务器；requests/curl 抓首页不能证明该查询有无结果。不得猜测、调用未授权隐藏 API。Word Sketch 参数从界面实际跳转取得，不自行猜 URL。
4. **区分访问状态**：只有正常结果页明确零匹配才记 `empty_results`；这仅是本查询无匹配，不是表达错误或不存在。尚在加载/仅脚本壳记 `js_required`；连接失败记 `fetch_failed`；验证码记 `captcha`，429 记 `rate_limited` 并遵守 Retry-After，本轮停止该站自动化，不换通道绕过。未取得例句就保留待核实，可转其他合法来源。状态定义与保密查询边界沿用[双语检索](bilingual-retrieval.md)。

## 离线入口

复用 `scripts/bilingual_queries.py --source skell`，从标准输入读公开或获准查询词；仅需 Python 3 标准库。原有双语默认来源不变，SkELL 分支只生成英语 Examples 入口，不生成 Google/Bing/Linguee 查询。输出 `not_requested`，不联网、不打开浏览器，不代表已检索。查询值按 UTF-8 百分号编码（空格 `%20`，保留字符也编码），不编码 URL 骨架。现有输入限制仍适用（非空、最多 500 字符、不含控制字符或双引号）。

示例入口：[status quo](https://skell.sketchengine.eu/#result?f=concordance&lang=en&query=status%20quo)。生成 URL 后仍须完成上述浏览器读取。

## 证据与结论

- 记录查询原文、语言、当前标签、实际 URL、访问日期、可见语料/界面版本；Word Sketch 另记 lemma、词性、关系与点击的搭配。读到结果列表与读过所引完整句分别记录，保存时不自动提升 CLI 的用户确认状态。
- 从实际读到的结果精选 2–3 条与本句义项、关系、用途相符的短而完整的例句；没有足够匹配例句就少给并说明缺口，不凑数。日常最终答复仍可只引用最强 1–2 条。逐字引用并附查询页链接，日期可随证据卡或实查记录保留，不必强塞进简短答复。完整句不可读时仅引确见短片段并标“不完整”，不得拼接或生成缺失上下文。DOM 高亮边界可能粘连单词，核对渲染文字/innerText 后引用，不自行改写。
- **总命中数、每百万词频率、展示例句数分开**：仅页面明确提供的总命中才记 total hits；`hits per million` 是归一化频率；Examples 至多展示 40 条筛选例句，不是总命中或随机代表性样本。未知总量留空，不从频率或展示条数反推。不用展示行数比较常用程度；不同参数/版本的数字不能直接对比。
- SkELL 从语料自动筛选句子与提取搭配，非模型生成，但也非人工规范审定。出现只支持特定用例，不证明整句普遍合语法、最地道或适用于任何语域；零命中不证明不存在。看不见原始出版者或全文时注明限制，不编造来源身份；有命中仍须判断本句适用性。
- 参考文件或历史验收中的引文、频率与版本只证明当时读到的内容，不能当作本轮实时证据；每次使用必须重新打开核对。
