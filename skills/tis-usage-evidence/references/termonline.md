# 术语在线：概念、学科与译名核对

## 来源与用途

入口：[术语在线](https://www.termonline.cn/)；[关于术语在线](https://www.termonline.cn/about)。关于页称其为“全国科学技术名词审定委员会着力打造的术语知识公共服务平台”；页脚写“全国科学技术名词审定委员会 授权 北京市电通电话技术开发有限公司 运营”。平台、运营方、具体条目来源分别记录。该页还说明平台融合其他机构成果，不能把全站内容统称为委员会审定名词。

用于核对中文规范名称、英文对应形式、学科、定义与概念边界。它在对应收录成果范围内提供权威术语依据，不能单凭命中证明每个语境都适用，也不能用外文同形或近义词自动合并概念。目标语词典补词义/语域，领域语料补搭配与真实用法，客户简报决定当前任务约束；这些证据各有用途。

## 查询协议

1. 仅查询公开或获准外查的最小术语；不提交整篇客户原稿、病例或识别信息，不登录、不上传。先确定用户句中概念、学科和目标读者；已有简报、客户术语表或当地命名规则优先约束交付。若与术语来源冲突，列出双方依据及影响，向用户确认冲突项，不能静默覆盖。
2. 在首页实际搜索框输入中文术语，必要时再查英文候选；通过界面选择精确/模糊匹配、来源或年度。检查实际库别。本次界面有“审定公布名词库”“征求意见名词库”“标准文件术语库”“海峡两岸名词对照库”“其他术语库”；不要把这些库混为一种审定状态。预公布、百科等身份也只按实际页面标识记录，未标明就写“未明确”。
3. 逐条点击“查看详情”，阅读基本释义。记录规范用词、英文原样、学科路径、定义、来源作品、公布年度、术语编码；版次、同义词、缩略形式和审定/预公布信息仅在页面确实显示时填写。公布年度不自动改称出版年或审定年，未显示版次就写未显示。不同学科同名条目分别比较定义；智能聚合中的百科内容、汇总英文和同页其他学科不能移作当前条目字段。
4. 保存当次实际搜索 URL 与详情 URL、访问日期、短小逐字引文；定义摘录与自己的定义概括分开。若需证明具体公布程序或版本，另开条目实际提供的来源作品/官方公布页核对；没有可读依据时保留“公布信息待核”，不从平台名、年份或搜索摘要推定。
5. 回到原句比较研究对象、条件、学科和用途，再给保留/有条件采用/替换/待核实结论。术语的概念对应和英文句中的搭配/冠词/语域分开查证，必要时补词典与领域语料。

搜索需要 JavaScript 浏览器。本次真实表单产生 `/search?searchText=…&t=…`，其中含动态参数；尚未验证可复用的稳定 URL 契约，因此本版不新增 `--source termonline` 或查询模板。使用首页和实际界面，复制页面真实地址，不猜内部 API、抓包逆向或构造隐藏请求。遇验证码、TLS、登录或反自动化限制即停止该路径，不绕过；说明失败位置，给出“首页→输入术语→选库/学科→查看详情”的人工路径。用户提供页面短摘录时标明“用户提供”，未亲自打开不声称已读官网。

## 最小证据记录

日常回答精选 1–2 条证据，无需列空表；需要证据卡时保留：

- 查询词、访问日期、平台与运营/发布身份；实际搜索 URL、实际详情 URL。
- 中文规范名称、英文原样、学科路径；逐字短引文、定义概括、来源作品、公布年度、版次、术语编码、可见同义词/缩略形式（缺项未显示）。
- 实际库别及页面显示的审定/征求意见/预公布/百科/未明确身份；依据是哪一页/字段。
- 阅读状态（未访问/仅搜索结果/已读条目）、公布信息核验状态、本句适用性与冲突项；核对者及读取方式。

例如“已读条目/公布信息待核”只说明已阅读条目但未独立核对公布文件；不是自动权威认证。仅生成链接仍为未访问。现有卡片状态继续沿用 unverified/text_read/audio_checked，不新增枚举、不自动升级：实际页面阅读与来源公布状态分栏描述；CLI 保存 text_read 仍需现有契约要求的用户明确确认。参考中的历史实查不是下一次任务的即时证据。
